# Privacy Policy — Finalbenchmark 2 Pro

**Last updated:** 23 June 2026

Finalbenchmark 2 Pro ("the app") is developed by Abhay Raj and distributed on the Google Play Store. This privacy policy explains what data the app collects, how it is used, and your rights as a user.

The short version: **the app does not collect, transmit, or share any personal data**. It runs entirely on your device.

---

## 1. Data the app does NOT collect

The app does **not** collect, store on remote servers, or share with any third party:

- Personal identifiers (name, email, phone number, account)
- Location data
- Device identifiers used for tracking
- Usage analytics or telemetry
- Crash reports to a third party
- Advertising identifiers

The app contains **no analytics SDK** (no Google Analytics, Firebase, Crashlytics, Sentry, Mixpanel, Amplitude, or similar). The app contains **no advertising SDK** (no AdMob, Meta Audience, Unity Ads, or similar).

---

## 2. Data stored on your device

All data generated by the app stays on your device in a local Room/SQLite database:

- **Benchmark results** (scores, timings, frequency samples)
- **Device hardware profile** (CPU info, GPU info, sensor list — read for benchmarking only)
- **App preferences** (theme, units, default benchmark settings)

This data is stored at `/data/data/com.zenithblue.fb2Pro/databases/` and is **never** transmitted off-device by the app. It is removed when you uninstall the app, and you can clear it manually from Android Settings → Apps → Finalbenchmark 2 Pro → Storage → Clear data.

---

## 3. Permissions

The app requests the following Android permissions. Each is required for a specific, documented in-app feature and is **not** used to collect personal data:

| Permission | Why it is needed |
|---|---|
| `INTERNET` | Open-source library dependencies and optional root-via-network checks (libsu). The app does not initiate outbound network calls of its own. |
| `CAMERA` | Optional camera sensor benchmark (read-only metadata; no images are captured or saved). |
| `READ_PHONE_STATE` | Read device model, build, IMEI-free identifiers for hardware profiling. |
| `ACCESS_WIFI_STATE` / `ACCESS_NETWORK_STATE` | Read Wi-Fi/connection metadata for the network benchmark. |
| `BLUETOOTH` / `BLUETOOTH_ADMIN` / `BLUETOOTH_CONNECT` / `BLUETOOTH_SCAN` | Optional Bluetooth hardware benchmark. |
| `BODY_SENSORS` | Read accelerometer/gyroscope for the sensor benchmark. |
| `ACTIVITY_RECOGNITION` | Detect stationary vs. moving state during stability scoring. |
| `READ_EXTERNAL_STORAGE` | Storage benchmark reads synthetic test files from app-private storage. |
| `NFC` | Detect NFC hardware presence for the device report. |
| `WAKE_LOCK` | Keep the screen on during long-running benchmarks. |
| `FOREGROUND_SERVICE` / `FOREGROUND_SERVICE_SPECIAL_USE` / `POST_NOTIFICATIONS` | Run a benchmark that continues when the app is backgrounded, with a visible notification. |

You can revoke any permission at any time via Android Settings. Revoking a permission will disable the corresponding benchmark feature; the rest of the app continues to work.

---

## 4. Third-party services

The app does not embed any third-party service that receives user data. The two libraries that can theoretically open network sockets are:

- **OkHttp** (`com.squareup.okhttp3:okhttp`) — a generic HTTP client, included for future use. The app does not make HTTP requests at runtime.
- **libsu** (`com.github.topjohnwu.libsu:core`) — a root-management library. Used only for in-app CPU governor tweaks on rooted devices. Does not make network calls.
